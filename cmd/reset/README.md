# reset — генератор методов Reset()

Утилита кодогенерации: создаёт методы `Reset()` для структур с директивой
`// generate:reset`. Метод возвращает состояние объекта к нулевым значениям.

## Запуск

Из корня проекта:

```bash
go run ./cmd/reset
```

С явным указанием корневой директории:

```bash
go run ./cmd/reset -dir ./internal
```

Через `go generate` (директива `//go:generate` в `cmd/shortener/main.go`):

```bash
go generate ./...
```

## Использование

1. Добавьте директиву `// generate:reset` в godoc-блок структуры:

   ```go
   // generate:reset
   type Counter struct {
       N    int
       Tags []string
   }
   ```

2. Запустите генератор. В директории пакета появится `reset.gen.go`:

   ```go
   // Code generated by cmd/reset. DO NOT EDIT.

   package mypkg

   // Reset сбрасывает состояние Counter к нулевым значениям.
   func (rs *Counter) Reset() {
       if rs == nil {
           return
       }
       rs.N = 0
       rs.Tags = rs.Tags[:0]
   }
   ```

3. Файл `reset.gen.go` коммитится в репозиторий.

Если в пакете нет структур с директивой, файл не создаётся, а устаревший —
удаляется.

## Правила сброса

| Тип поля                       | Действие                                        |
|--------------------------------|-------------------------------------------------|
| примитивы (числа, string, bool)| нулевое значение: `0`, `""`, `false`            |
| слайс                          | обрезка без зануления: `s = s[:0]`              |
| мапа                           | `clear(m)`                                      |
| указатель на примитив          | `*p = zero`, если `p != nil`                    |
| указатель на структуру         | вызов `p.Reset()` или рекурсивный сброс полей   |
| вложенная структура            | вызов `Reset()` или рекурсивный сброс полей     |
| интерфейс                      | type assertion на `interface{ Reset() }`        |
| канал, функция, массив         | не сбрасываются (помечаются комментарием)       |
| тип из внешнего пакета         | не сбрасывается (помечается комментарием)       |

## Ограничения

- Рефлексия в сгенерированном коде не используется — только прямые
  обращения к полям.
- Скрытые директории, `vendor`, `testdata` и `node_modules` пропускаются.
