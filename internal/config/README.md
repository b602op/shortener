# internal/config

В этом пакете хранятся конфигурации приложения.

Загрузку конфигурации можно реализовать из различных источников, например: файлов, переменных окружения, баз данных и других.

# Конфигурация сервиса сокращения URL

Сервис поддерживает конфигурацию через аргументы командной строки.

## Флаги

- `-a` - адрес запуска HTTP-сервера (по умолчанию: `localhost:8080`)
- `-b` - базовый адрес результирующего сокращённого URL (по умолчанию: `http://localhost:8080`)

## Примеры использования

### Запуск с настройками по умолчанию
```bash
go run cmd/shortener/main.go
```

### Запуск на другом порту
```bash
go run cmd/shortener/main.go -a :9000
```

### Запуск с кастомным базовым URL
```bash
go run cmd/shortener/main.go -b http://mysite.com
```

### Полная настройка
```bash
go run cmd/shortener/main.go -a :8080 -b https://short.mysite.com
```

## Пакет config

Конфигурация реализована в отдельном пакете `internal/config`:

- `Config` - структура с полями конфигурации
- `New()` - функция для создания конфигурации из командной строки
- `NewTest()` - функция для создания тестовой конфигурации
- `GetServerAddress()` - получить адрес сервера
- `GetBaseURL()` - получить базовый URL

## Интеграция

Конфигурация передается в обработчики через функцию `Handler()`:

```go
cfg, err := config.New()
if err != nil {
    log.Fatal(err)
}
r := handler.Handler(cfg)
```
